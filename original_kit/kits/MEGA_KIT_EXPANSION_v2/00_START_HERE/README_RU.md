# MEGA KIT v2 — дополнение к твоему драм-киту

**Что это.** Твой архив (`!mylancore drumkit @StarBeats` + `treit1 kit`, 320 сэмплов) — чисто трэп/фонк-пак: кики, снейры, клэпы, хэты, перки, 808, воксы. В нём нет мелодики, акустики, оркестровки, FX-переходов, томов, лупов и филлов — на нём нельзя записать ни хаус, ни амапиано, ни бумбэп, ни что-то «живое».

Я достроил кит до состояния «делаю любую музыку»: **1272 сэмпла (20.9 минуты звука), 48 мелодических инструментов, 17 филлов, 18 лупов, 31 MIDI, 72 SFZ-мапы, 12 готовых раскладок пэдов.**

Оригинал внутрь не дублирован (иначе архив удваивается) — структура папок стыкуется, слить = 2 минуты (ниже).

## Как собрать один большой кит

1. Распакуй архив.
2. Перетащи папки `01_…`–`20_…` в свою `Dkits` рядом с `!mylancore drumkit @StarBeats` и `treit1 kit`.

Хочешь разложить и старые сэмплы по новым папкам — в `00_START_HERE/original_kit_to_new_folders.csv` для каждого из 319 старых файлов указана целевая папка. Итого ~1600 сэмплов в одной структуре.

## Мелодика: как играть

- **14 инструментов** — полная хроматика `C4…B4` (12 файлов), остальные — **4 опорные ноты** `C4, D#4, F#4, A4` (шаг 1.5 полутона, питч-шифт до ±1.5 полутона сохраняет строй).
- Диез в имени файла — буква `s`: `C#4 → Cs4`.
- Основные (12 нот): piano soft/bright, rhodes, organ, music_box, marimba, pluck_synth, saw_lead, supersaw, pad_warm, pad_choir, strings, guitar_clean, guitar_dist.
- Все тональные сэмплы проверены по FFT: **±1 цент** у 808/саба/лог-драмов.

## 808, лог-драмы, бас

`12_808_SUB/808_tuned_clean|hard|soft|reese` — C1–B1, 12 нот. `13_BASS/log_drum_soft|hard` — C1–B1 для амапиано. `13_BASS/acid_303`, `13_BASS/wobble` — C2–B2. `808_glide` — готовые слайды.

## Быстрый старт (FL Studio / сэмплер)

`18_KIT_MAPS/drum_kits/` — 12 файлов `*_PAD_LAYOUT.txt`: что кинуть на пэды 1–16 (trap, drill, phonk, boom-bap/lofi, house/techno, dnb, rock, amapiano, UKG, dubstep/breakbeat, orchestral, melodic). Рядом `*.sfz`. Мелодика — `18_KIT_MAPS/melodic_kits/*.sfz`, ноты растянуты по клавиатуре с сохранением строя.

## MIDI

`17_MIDI/drum_patterns` — паттерны всех лупов + скелеты (dubstep, footwork, citypop, amapiano). `17_MIDI/progressions` — 6 прогрессий в C/F/G.

## Технические характеристики

- 44.1 кГц / 16 бит WAV, пик −1 dB, тишина обрезана, фейды без щелчков.
- Ваншоты — моно; FX, текстуры и часть лупов — стерео (столбец `ch` в `KIT_INDEX.csv`).
- Все 1272 файла проверены автоматически: нет тишины, клиппинга, NaN, DC, щелчков на конце.

## GitHub

Коннектора GitHub в Arena нет (платформа его не предоставляет), поэтому пуш делаешь ты — я подготовил папку **`GITHUB_REPO_READY`**: `push_to_github.sh` + инструкция `PUSH_TO_GITHUB.md`. Три шага: создать пустой репозиторий → `bash push_to_github.sh <url>` → прикрепить архив кита к Release (у GitHub лимит 100 МБ на файл в репо и 2 ГБ на ассет релиза).
В репозиторий также кладётся **генератор** (`generator/`) — кит можно пересобрать с нуля одной командой.

## Честные оговорки

- Всё синтезировано с нуля (аддитивный синтез, FM, физическое моделирование струны, формантный синтез) — это не записи живых барабанов и рояля. В миксе и под обработкой работает, но «записанный» рояль/скрипка звучат иначе.
- Вокала как такового нет: `vocal_aah / vocal_ooh / vocal_chop / shout` — формантный синтез.
- Лупы — 2 такта; основа кита — ваншоты.
